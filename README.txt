ASCENDED V3

WEB:
Upload everything inside web/ to the root of your existing GitHub Pages repository:
index.html, manifest.webmanifest, sw.js, logo.png

FEATURES:
- Screenshot-inspired dashboard layout
- Mission selection screen
- Automated quest claiming for focus and steps
- Daily XP, levels, ranks, stats, skills, inventory and achievements
- Local save data
- PWA install support
- Mobile bottom navigation

ANDROID:
Open the android/ folder in Android Studio and build/run it.
The Android wrapper includes the native Android step-counter sensor, when the device supports it.
